# Khushboo Singh — Research & AI Portfolio

Responsive, dark-themed personal portfolio based on the uploaded resume and public LinkedIn profile. It presents psychology, AI, research methods, and cognitive neuroscience interests.

## Files
- `index.html` — portfolio content and sections
- `styles.css` — original responsive visual system
- `portfolio-additions.css` — research cards, timeline, project grid, awards and responsive additions
- `script.js` — mobile navigation
- `portfolio-content-notes.md` — content source notes and project details
- `resume.pdf` — supplied resume, included for convenience

## Run locally
Extract the ZIP and open `index.html` in a modern browser. No build step or framework is required. Internet access is needed for the Google Fonts used by the design; the page still works without them.
